# Lead Radar

Ищет локальный бизнес (кафе, кофейни, цветочные, барбершопы, салоны, пекарни, автосервисы) в Москве и Подмосковье и показывает, у кого нет сайта или вместо сайта стоит соцсеть.

**Сайт:** https://ermin372.github.io/lead-radar/

Статика без сборки: HTML, CSS и JS-модули. Деплой на GitHub Pages через GitHub Actions. Ключей в репозитории нет: они вводятся на странице и хранятся только в `localStorage` твоего браузера.

## Сколько это стоит (важно)

| API | Бесплатно? |
|---|---|
| JavaScript API (карта) | да, при соблюдении [условий](https://yandex.ru/dev/commercial/doc/ru/) |
| API Поиска по организациям | **нет**. Только пробный тариф: **7 дней по 100 запросов в сутки**, дальше от 20 800 ₽ в месяц ([тарифы](https://yandex.ru/dev/tariffs/doc/ru/geosearch/prices/)) |
| OpenStreetMap (Overpass) | да, без ключа, но данных о сайтах меньше |

Пробный период начинается **в момент подключения** в кабинете. Подключай его, когда сайт уже задеплоен и ты готов искать.

В приложении стоит жёсткий стоп на 90% суточного лимита: при лимите 100 это 90 запросов. Счётчик сбрасывается в 00:00 по Москве. По какому часовому поясу считает сутки сам Яндекс, в документации не нашёл. Счётчик живёт в одном браузере: если искать с телефона и с ноутбука, каждый считает отдельно.

## Ключи

Нужны два разных ключа, оба берутся в [Кабинете разработчика](https://developer.tech.yandex.ru).

### 1. JavaScript API (карта)

1. Кабинет → «Подключить API» → **JavaScript API и HTTP Геокодер** → бесплатный тариф.
2. Открой ключ → «Изменить» → **Ограничение по HTTP Referer** → одна строка: `ermin372.github.io`.
   - без `https://`, без слэша и без `/lead-radar`;
   - не пиши просто `github.io`: поддомены разрешаются автоматически, и ключ заработает на любом чужом github.io-сайте;
   - JS API 3.0 работает **только** с ключами, у которых этот Referer заполнен ([дока](https://yandex.ru/maps-api/docs/js-api/common/quickstart.html)).
3. Ограничение по IP оставь пустым, секрет не создавай.
4. Ключ и ограничения начинают работать примерно через 15 минут.

Из-за Referer карта открывается только на `ermin372.github.io`, на `localhost` не работает. Так и задумано.

### 2. API Поиска по организациям (данные)

1. Кабинет → «Подключить API» → **API Поиска по организациям** → тариф «Пробный на 7 дней», 100 запросов в сутки → принять оферту → «Подключить».
2. В настройках этого ключа ограничение по Referer, судя по кабинету, применяется только к JavaScript API. Поэтому ключ поиска защищён только тем, что лежит у тебя в браузере. Не вставляй его на чужих сайтах и не свети в скриншотах.
3. Активация занимает до 15 минут. До этого API отвечает 403.

### 3. Ввести ключи на сайте

Кнопка «Ключи» справа сверху → вставить оба → «Сохранить». Кнопка «Забыть ключи» удаляет их из браузера.

## Как пользоваться

1. Выбери источник: **Яндекс** (тратит квоту) или **OpenStreetMap** (бесплатно).
2. Выбери категорию или «Свой запрос…».
3. Выбери область: Москва целиком, округ, город Подмосковья или «Видимая область карты». Границы пресетов приблизительные.
4. «Найти (−1 запрос)» → первые 50 организаций.
5. «Ещё 50» тратит ещё 1 запрос. «Загрузить всё» сначала спросит подтверждение и покажет, сколько запросов уйдёт. Максимум 21 страница (это ~1050 организаций) на один поиск: так ограничен API (`skip` ≤ 1000).
6. Фильтр по статусу **приглушает** неподходящие строки и метки, но не удаляет их.
7. Клик по строке показывает организацию на карте, клик по метке подсвечивает строку.
8. «Скачать Excel (N)» сохраняет `.xlsx` со строками, которые подходят под текущий фильтр. Например, выбери чип «Нет сайта», и в файл попадут только организации без сайта. Для OpenStreetMap файл скачивается сразу, для Яндекса только после подтверждения (см. ниже про условия).

Совет: ищи по округам, а не по всей Москве. Яндекс отдаёт «наиболее подходящие» результаты, а не все. Чем меньше область, тем полнее выдача.

| Статус | Когда |

## Что приложение делает ради условий Яндекса

По [условиям API Поиска по организациям](https://yandex.ru/dev/tariffs/doc/ru/geosearch/terms/) и [соглашению](https://yandex.ru/legal/maps_api/ru/):

- **Само ничего не сохраняет.** Результаты живут в памяти вкладки до перезагрузки, кэша в localStorage, sessionStorage или IndexedDB нет. Автотест это проверяет.
- **Не меняет порядок выдачи.** Сортировка для данных Яндекса выключена, фильтр только приглушает строки.
- **Показывает данные на Яндекс Карте.** Без ключа карты поиск через Яндекс заблокирован.
- **Не скрывает копирайты и логотип.** Кнопка «Открыть в Картах» штатная (`YMapOpenMapsButton`). Если модуль не загрузился, показываем свою ссылку.
- Рядом с таблицей подпись, что данные предоставлены Яндексом.

**Выгрузка в Excel из Яндекса нарушает условия, она включена по решению владельца, на его риск.** По п. 2.2 [условий](https://yandex.ru/dev/tariffs/doc/ru/geosearch/terms/) результаты нельзя сохранять, а расширенной лицензии с сохранением для этого API нет ([источник](https://yandex.ru/dev/commercial/doc/ru/concepts/geosearch)). За нарушение Яндекс вправе заблокировать ключ без предупреждения. Перед каждой выгрузкой приложение спрашивает подтверждение.

Ещё одна серая зона: кнопка «Скопировать» кладёт контакт в буфер обмена. Если дальше сохранять контакты у себя, это уже хранение данных, а его условия запрещают (кроме 30-дневного кэша). И ещё: пробный период по оферте даётся «в целях анализа качества и эффективности». Решать тебе.

Для OpenStreetMap ограничений нет (лицензия ODbL, нужна только атрибуция), поэтому там сортировка включена.

## Если что-то не работает: DevTools

Открой DevTools (F12 или Cmd+Opt+I).

**Console:** ошибки с префиксами `[map]` и `[search]`.
- `[map] Error: скрипт JS API не загрузился`: неверный ключ карты, нет Referer `ermin372.github.io` в настройках ключа или он ещё не активировался.
- `[map] YMapOpenMapsButton недоступен`: это не ошибка, стоит запасная ссылка «Открыть в Яндекс Картах».

**Network:** фильтр `search-maps`.
- `200`: всё ок. Во вкладке Response виден JSON с `features`.
- `403`: ключ поиска неверный, ещё не активирован или пробный период кончился.
- `400`: смотри `message` в ответе.
- `429`: слишком часто, подожди минуту.
- `(failed)` или `CORS error`: обычно блокировщик рекламы. Отключи его для сайта.

Фильтр `api-maps` показывает загрузку карты. Если там 403, проблема с ключом JavaScript API или его Referer.

## Структура

```
index.html            разметка
```

## Тесты

Нужен Node 18+ и Playwright с Chromium.

```bash
node tests/smoke.mjs
```

API Яндекса, JS API и Overpass в тестах подменяются заглушками, данные синтетические. Тесты проверяют интерфейс, параметры запроса, классификацию, квоту, фильтр, отсутствие данных в хранилище, мобильную вёрстку и темы. Живой API так не проверить, для него нужен ручной прогон на сайте.

## Деплой сайта

Пуш в `main` запускает `.github/workflows/pages.yml`. В Settings → Pages → Source должно стоять **GitHub Actions**. Workflow публикует только `index.html`, `css/` и `js/`, а перед публикацией проверяет, что в файлы не попало ничего похожего на ключ.
